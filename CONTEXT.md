# Glossary

- **LiveSession**: A WebSocket connection established between the React client and the Gemini Live API, authenticated via an Ephemeral Token.
- **EphemeralToken**: A short-lived authentication token generated by the Next.js API route to authorize the client-side LiveSession without exposing the API key.
- **AudioPipeline**: The client-side Web Audio API implementation consisting of an `AudioContext` and `AudioWorkletNode` responsible for capturing, resampling (to 16kHz PCM), and playing back (24kHz PCM) real-time audio.
- **FluidImmersion**: The pedagogical UX state where the user and the AI converse naturally without strict interruptions.
- **PracticeSession**: A persisted database record containing the full text transcript, duration, and metadata of a completed `LiveSession`.
- **KnowledgeExtraction**: The backend process where an LLM (Gemini 1.5 Flash) analyzes a `PracticeSession` transcript to identify grammatical errors, extract new vocabulary, and generate structured learning items.
- **Flashcard**: An entity generated via `KnowledgeExtraction` representing a vocabulary item or phrase, managed by a Spaced Repetition System (SRS) algorithm to optimize recall.
- **FillInTheBlank**: A dynamically generated exercise targeting specific weaknesses identified during `KnowledgeExtraction`, simulating Duolingo-style active recall.
- **StudyMapSync**: An automated pipeline that logs the daily progress (sessions, flashcards, time studied) directly into the Ideaverse (Obsidian) and Google Workspace (Calendar/Tasks) to track the B2 goal.
- **ContextualPrompting**: The mechanism of injecting Rodrigo's macro goal (B2 by April 2027) and daily streak stats into the Gemini Live system prompt, transforming the AI into an accountability partner.
